# Chapter 1: Intro

## What is this course about?

This is a one-shot (very long) course on **Linux for DevOps engineers**. It starts from zero. You do not need any earlier knowledge. By the end you will be able to set up and manage Linux servers, which is a core skill for a DevOps engineer.

## Why should a DevOps engineer learn Linux?

- Most servers in companies run Linux, not Windows.
- Cloud machines (AWS, Azure, GCP) are mostly Linux machines.
- Tools such as Docker, Kubernetes, Jenkins and Terraform run mainly on Linux.
- In interviews, Linux questions are always asked.

## What will you learn?

| Topic | What you will understand |
|-------|--------------------------|
| How the internet works | Data centers, cables, servers, clients, DNS |
| What Linux is | Operating system, kernel, shell, bootloader |
| Setting up a Linux server | Creating an Ubuntu machine on AWS EC2 |
| Basic commands | Files, folders, viewing files, copying, moving, links |
| Advanced commands | SSH, disk usage, processes, memory, package managers |
| Users and groups | Creating users, groups, sudo |
| File management | Permissions, ownership, zip, tar |
| File transfer | scp and rsync |
| Networking commands | ping, netstat, traceroute, curl, nmap and more |
| Pro commands | awk, sed, grep |
| Volume management | AWS EBS volumes, attaching and mounting |
| LVM | Physical volumes, volume groups, logical volumes |

## Interview tip from the course

Many small things explained in the video are "hidden interview questions". The teacher advises you not to skip even one minute, and to **practice every command yourself** on a real Linux machine. The saying used is: *"Bleed more in practice so that you sweat less in war."* This means: make more mistakes while practicing so that you feel confident in real interviews and jobs.

## How to practice

1. Create a free-tier Ubuntu server on AWS (explained in Chapter 3).
2. Connect to it using SSH (explained in Chapter 5).
3. Type every command from these notes and see the output.
4. Break things on purpose (in your practice machine) and learn how to fix them.
