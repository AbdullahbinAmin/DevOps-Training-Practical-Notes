# Chapter 2 — DevOps Prerequisite & Course Announcement

## Objective
Explain that Kubernetes is only **one part** of becoming a full DevOps Engineer, and mention what else is needed. This chapter is mostly an announcement, not a technical practical.

## Key Teaching Points

1. Kubernetes alone does not make someone a DevOps Engineer.
2. To become a complete DevOps Engineer, a person also needs to learn:
   - Terraform (Infrastructure as Code)
   - Ansible (Configuration Management)
   - Prometheus (Monitoring)
   - Grafana (Visualization/Dashboards)
   - Resume building
   - LinkedIn profile building

## Classroom Note
This chapter has no hands-on/practical content. It is purely context-setting: telling students that this Kubernetes course is one piece of a bigger DevOps learning journey. You can mention this briefly to students and move on quickly.

## Final Result
Students understand that this course focuses deeply on Kubernetes, but a full DevOps skill set requires more tools beyond Kubernetes alone.
