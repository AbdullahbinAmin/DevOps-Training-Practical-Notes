# Chapter 1 — Course Intro

## Objective
Understand what the course teaches, who it is for, and see the final demo (a website going live with one Terraform command).

## What the course contains
- More than 9 hours of practical content, from basic to advanced.
- Terraform and AWS are learned together. You will understand AWS services such as EC2, VPC, S3 and IAM in detail.
- Learn-while-doing: almost everything is practical.
- Basic programming ideas used in Terraform: loops, objects, lists, `for` loops, operators, conditions.
- Projects and tasks are included.
- Advanced topics: Terraform Cloud, modules, workspaces, state management, resource lifecycle, dependencies, and publishing your own module in the Terraform Registry.

## Who is it for
- Beginners who are not comfortable with AWS yet.
- People who want to focus on Terraform (used with the AWS provider).

## Why AWS concepts come first
If you do not understand how networking or S3 works, you cannot write correct Terraform for it. So for each topic the course does this order:

```text
Understand the concept → Create it manually in the console → Create it with Terraform
```

## Demo shown in the video
A local static website (`index.html`, `styles.css`) is published on the internet with a single Terraform command. Terraform prints a website link, and the site opens in the browser within seconds. You will build this yourself in **Chapter 21**.

## Prerequisites for the whole course
- OS: Windows, macOS or Linux
- RAM: 4 GB or more
- Internet connection
- Required software (installed in the next chapters): Terraform, AWS CLI, VS Code
- Required account: AWS account (with a debit or credit card for verification)
- Required permissions: You need admin rights on your computer to install software
