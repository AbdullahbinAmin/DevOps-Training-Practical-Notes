## How to Use These Notes in Class
1. Open the chapter file for the day's topic.
2. Follow **Prerequisites** and **Pre-Check** first to make sure your environment is ready.
3. Run each command exactly as shown, in order — do not skip steps.
4. Use the **Verify** / **Expected result** lines after each step to confirm you're on track before moving to the next step.
5. If something breaks, check the **Troubleshooting** section at the end of that chapter first.
6. **Cleanup** sections are optional between chapters, but recommended if your server's disk/resources get tight.
